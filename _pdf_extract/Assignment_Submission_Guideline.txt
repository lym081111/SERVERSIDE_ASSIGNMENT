Guideline Recommendation (Report- Part): Functional Requirements
• Include 1 screenshot per module (optional but recommended).
• State the module name and purpose: Briefly describe what the module is for.
• List each core feature : Number them clearly (Feature 1, Feature 2, etc.).
• Ensure clear explanation for each core functional requirement (For every feature, 
you may describe):
• What the user does (input or action).
• What the system does (process or response).
• Data/fields involved (example: name, date, amount).
• Validation rules (example: required fields, limits).
• Expected outcome (what happens after the action?).
Keep it readable, no need for multiple screenshots.
